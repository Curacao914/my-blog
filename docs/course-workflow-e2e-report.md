# 课程整理工作流验收记录

更新日期：2026-06-26

## 本轮结论

课程模块已改为“浏览器本地解析普通资料 + 独立在线 OCR + Vercel 单步骤课程处理”的在线优先路径。普通用户不需要启动本地服务。工作台采用课程库、三步导入向导和单阶段课内工作台，不再把偏好、大纲、正文、审查和最终笔记全部纵向铺开。

自动化验证没有调用真实 PaddleOCR 或真实课程模型，也没有声称线上第三方服务已跑通。Hugging Face Space API、签名、临时文件删除、文字结果清理和课程状态机使用 Mock/确定性数据验证；真实外部服务需在两仓库部署后用一份非敏感材料验收。

## 输入、分组与数据边界

浏览器端直接解析：

- SRT：去除字幕时间轴，保留行号、时间和来源映射；
- 文字型 PPTX：逐页提取正文和备注，低文字密度课件转入在线识别；
- DOCX：提取标题、段落和表格文字，图片只产生识别提示；
- TXT：处理 UTF-8、BOM、UTF-16，并拒绝无法可靠识别的乱码；
- Markdown：保留标题、列表、引用、表格和代码块结构。

PDF、常见图片和低文字密度 PPTX 使用在线 OCR。网页从 `/api/courses/ocr/session` 获取短期签名后，原文件直接上传到 OCR Space；Space 将临时文件提交 PaddleOCR 后立即删除本地副本。识别完成后只返回逐页 Markdown，课程数据库只保存文字、来源页码和任务状态。网页成功取回结果后主动删除 OCR 任务；异常遗留由 TTL 清理。

文件选择支持多次追加、拖拽、去重、单文件移除和材料角色调整。课次建议综合：

- 日期；
- 第 N 课、讲、节、周等显式信号；
- 文档标题和前部文字；
- 清理后的文件名相似度。

所有自动建议均在导入前进入“确认课次”，用户可以改名、排序、新建课次、移动资料和调整材料作用，因此乱码或不规则命名不会被强制当成最终分组。

## 在线 OCR 服务

OCR Space 暴露：

- `GET /health`
- `POST /api/ocr/jobs`
- `GET /api/ocr/jobs/{id}`
- `GET /api/ocr/jobs/{id}/result`
- `DELETE /api/ocr/jobs/{id}`

已验证：

- 未签名上传被拒绝；
- 上传签名有 scope、过期时间和文件大小上限；
- 原始临时文件只在提交 Paddle 时存在，提交后立即删除；
- Paddle JSONL 被转换为逐页 Markdown；
- 远程图片 URL 不进入课程结果；
- OCR 任务结果可主动删除并由 TTL 兜底；
- 默认并发软上限为 2；
- 默认每日应用软预算为 18,000 页，可通过环境变量调整；
- Gradio 直接上传页可选配置访问码。

## 课程工作流

一门课程可以包含多节课。每次只处理第一节尚未完成且当前可执行的课：

```text
导入纯文字资料
→ 保存课程偏好
→ 在线生成本课大纲
→ 人工编辑、锁定和批准
→ 程序按行数/字符数拆分节点
→ Writer 生成一个节点
→ 独立 Reviewer 检查该节点
→ 人工批准或局部修订
→ 全部节点批准后拼装
→ Final Reviewer
→ 完成本课并进入下一课
```

网页通过 `POST /api/courses/jobs/:id/run-next` 每次只执行一个持久化步骤。该接口先校验服务端 owner，再领取带租约的任务，调用角色模型，验证结构化输出并通过 repository 门禁写回。浏览器关闭后尚未开始的步骤暂停；重新打开课程会从 Supabase 中的持久化状态继续。

质量门已验证：

- 大纲必须从第 1 行开始覆盖完整转录，范围越界或留空会被拒绝；
- 默认按 200 行和字符双阈值拆分节点；
- Writer、Reviewer 和人工批准相互独立；
- 当前草稿版本未经对应 Reviewer 不能批准；
- Reviewer `revise` 只回流当前节点；
- 达到自动修订次数上限后等待人工判断；
- 所有节点批准前不能拼装全文；
- Final Reviewer `revise` 按 nodeId 回流，`human_review` 进入人工最终确认；
- 质量意见不会被误报为技术失败；
- 第一课完成后自动进入下一节尚未完成的课；
- 暂停、恢复、失败重试、租约和幂等键均由服务端控制。

## 前端验收

课程模块现在分为：

1. 课程库；
2. 导入资料：选择资料 → 确认课次 → 确认导入；
3. 课内工作台：资料/偏好/大纲/正文/审查/整理/完成。

课内页面只显示当前阶段；左侧课次列表独立滚动，服务状态、来源和诊断信息按需展开。文件读取、OCR、在线写作和保存操作均提供按钮禁用、旋转进度、页数/文件数进度和淡入过渡，不再以无反馈停顿表现。

Today 与 Reading 也完成边界调整：

- Today 的所有视图过滤阅读材料；
- “今日阅读”标签已移除；
- Focus 事项保留完成勾选与编辑按钮；
- 阅读材料只出现在 Reading Box；
- 用户点击“安排阅读”时才创建一条关联日程，原阅读材料仍保留在阅读箱。
