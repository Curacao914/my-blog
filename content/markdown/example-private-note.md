# Markdown 内容中转示例

这个文件用于演示从 Markdown 导入内容中转层。

默认配置是：

- 草稿；
- 私有；
- 不进入搜索、RSS 或 sitemap；
- 需要通过内容配置台逐篇决定是否公开。
